# projeto_loja_Vitrual_Disco_de_vinil

Loja virtual simples para venda de discos de vinil.

## Funcionalidades

- Catálogo com discos de vinil
- Adição de itens no carrinho
- Total do carrinho em reais (BRL)
- Persistência do carrinho no navegador (`localStorage`)
- Limpeza do carrinho

## Como executar

Como o projeto é estático, basta abrir o arquivo `index.html` no navegador.

Opcionalmente, rode com servidor local:

```bash
python -m http.server 8000
```

Depois acesse `http://localhost:8000`.
